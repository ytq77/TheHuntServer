# TheHuntServer 0.1.0-preview.5

Windows 无缝模式和 Linux BBSC 配方默认将召唤搜索、发布间隔设为两秒，减少较长轮询错过入房信令时机的机会。普通联机模式保持原行为，账号、数据库与监听端口不变。

- 本版打包已提交的两秒轮询修改，Windows 管理窗口没有新增切换开关。
- 更频繁的请求会增加匹配接口和日志开销，包括部分尚未摇铃时的在线查询；它不改变战斗同步频率。
- 此前在同一组双人条件下的两秒对照成功入房并正常移动，但不代表所有网络和多人负载均已验收。详见[召唤轮询说明](../summon-polling.md)。
- 现有服务只有在升级并重启后才使用新参数；客户端应正常退出再启动，以重新获取服务配置。
- Windows 请先停止两种服务，再使用“检查更新”或完整安装包升级，保留本机账号和配置。Linux 请核对自己的实际部署命令；本次发布不会自动修改私人服务器。
- 需要恢复原间隔时，将无缝游戏服务的 `--summon-interval 2` 改为 `--summon-interval 0`，再重启该服务；`0` 沿用原模板的搜索35秒、发布30秒。不要重建账号数据库。

## 验证范围

两秒启动参数及普通/无缝模式隔离检查已通过。此前同一功能提交已通过 Windows 原生构建与回归、Linux 干净构建与协议回归；本版标签构建会再次验证并生成完整 Windows 包、固定上游源码包、Linux 配方和 SHA256 校验文件。公开包及构建结果以对应 Release 和 Actions 为准，不将构建成功扩大为新增双人实机验收。
