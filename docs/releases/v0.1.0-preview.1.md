# TheHuntServer 0.1.0-preview.1

首个独立服务端仓库版本，由 Windows test3 开服工具与公开云端部署配方整理。

- Windows 原生普通联机和 BBSC 无缝联机服务，附运行库，无需 Docker。
- 启动就绪后逐项输出客户端地址；账号由开服电脑本地持久保存，两模式独立。
- 保留 STUN 4/6 字节兼容和独立召唤 WebAPI 修复。
- 修正 Windows 开服电脑自身登录地址错误。
- 提供 Linux 云端配方、部署/备份/维护/排错说明。
- 自动构建测试，产出 Windows 包、固定上游源码包、Linux 配方与 SHA256；版本标签通过后发布。

使用前阅读 README 与验证范围。Relay 仅适合一组可信玩家；本预览版不安装 Windows 服务，也不自动开放防火墙。
