# TheHuntServer 0.1.0-preview.2

Windows 新增本地管理窗口，双击 `Server.exe` 使用，不需要输入命令。

- 普通联机与 BBSC 无缝联机分别启动、停止，显示进程和接口状态。
- 从本机网卡选择局域网或 VPN IPv4；客户端字段逐项复制或一次全部复制。
- 「连接信息」与「联机账号」使用紧凑的固定尺寸页签，以底色标记当前页面；悬停、聚焦和切换均不改变尺寸。
- 联机账号列表、新建、改名、重置密码、验证密码及删除。
- 改名、重置及删除需先停止对应模式；修改前自动创建并校验 SQLite 备份。删除还需输入完整账号名确认。
- 改名保留账号 ID；验证密码不登录游戏会话；密码通过标准输入传递，不写进配置或日志。
- 关闭窗口会停止本窗口启动的服务；后台异常关闭时由 Windows Job 回收其子进程。
- `Server-CLI.cmd` 保留命令行入口。Linux 配方与游戏联机协议不变。

账号存在开服电脑，普通与无缝模式各自独立；玩家角色存档不由账号页修改。更新已有环境时保留配置和数据库，步骤见 Windows 教程。
