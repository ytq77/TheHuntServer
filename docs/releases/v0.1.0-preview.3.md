# TheHuntServer 0.1.0-preview.3

- Windows 管理窗口新增「检查更新」，可查看中文发布说明并选择稳定版或预览版频道。
- 支持可选的本机 HTTP 代理和 GitHub 下载加速前缀，默认直连。
- 自动下载后按 GitHub 提供的 SHA256 和大小校验，由独立助手备份、替换程序并重新打开。
- 保留账号数据库、监听地址、已有世界和记分板配置；安装前需停止两种服务。
- 更新期间阻止重复启动；文件被占用或替换失败时回滚已替换的程序。

自动更新助手已通过独立安装目录的状态保留、损坏包和越界路径拒绝、占用回滚、运行中拒绝更新、父进程退出等待和重新启动验证。第三方加速站需使用自己的地址测试。首次启用此功能仍需手动安装本版，详见 `docs/updates.md`。
